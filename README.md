# Diwali Sales Data Analysis

## 📌 Project Overview
This project performs an Exploratory Data Analysis (EDA) on Diwali sales data using Python. The goal is to uncover key sales trends, customer demographics, and purchasing patterns to help business stakeholders optimize marketing strategies and inventory management for holiday sales.

---

## 📊 Key Insights & Findings
* **Demographics:** Female buyers contributed significantly more to total sales compared to male buyers.
* **Age Group:** The majority of buyers belong to the **26–35 age group**.
* **Top States:** Uttar Pradesh, Maharashtra, and Karnataka generated the highest number of orders and total revenue.
* **Product Categories:** Food, Clothing, and Electronics were the top-selling product categories.

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python 3.x
* **Data Manipulation:** `pandas`, `numpy`
* **Data Visualization:** `matplotlib`, `seaborn`
* **Environment:** Google Colab / VS Code
